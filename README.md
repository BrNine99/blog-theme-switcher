
# Blog Theme Switcher

Blog pessoal desenvolvido para praticar HTML, CSS, JavaScript e Web Storage API.

## 📌 Sobre o projeto

O projeto permite alternar entre os temas claro e escuro, salvando a preferência do usuário no navegador por meio do `localStorage`.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Web Storage API (localStorage)

## ⚙️ Funcionalidades

- Alternância entre tema claro e escuro
- Armazenamento da preferência do usuário
- Recuperação do tema ao recarregar a página
- Layout responsivo

## 📂 Estrutura do projeto

blog-theme-switcher/
├── index.html
├── style.css
├── script.js
└── README.md

## 💻 Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

## 🎯 Objetivo

Praticar manipulação do DOM, eventos JavaScript e armazenamento de dados no navegador.
